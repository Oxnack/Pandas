# Pandas Мега-шпора

Один скрипт, который показывает основные возможности pandas: от создания данных до графиков.

## Быстрый старт

```bash
# Установка зависимостей
pip install pandas numpy matplotlib seaborn openpyxl

# Запуск
python3 main.py
```

## Что внутри

- Генерация тестовых данных (1000 записей)
- Фильтрация, группировка, сводные таблицы
- Заполнение пропусков
- Объединение таблиц (merge/join/concat)
- Временные ряды (resample, rolling)
- 9 типов графиков (линейные, гистограммы, boxplot, scatter, heatmap и др.)
- Экспорт в CSV/Excel

## Важно

Для pandas ≥ 2.2.0 в коде используется `'ME'` вместо устаревшего `'M'` для месячного ресемплинга.

## Результаты

После выполнения создаются файлы:
- `pandas_mega_cheatsheet_plots.png` — все графики
- `pandas_export.csv` — данные
- `pandas_export.xlsx` — данные

## Настройка

Меняйте параметры в первой части скрипта:
- `n_rows` — количество строк
- `np.random.normal(1000, 200)` — распределение продаж
- Период дат — `pd.date_range('2024-01-01', periods=n_rows, freq='D')`
